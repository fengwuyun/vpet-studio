# 素材生成流程完全指南

> 本文档说明在 VPet Studio 中「从一张图片到游戏里会动的桌宠」的完整流程，以及每一步的规范依据。
> 适用于画师、AI 绘图用户与零基础模组作者。

## 总览：五步流水线

```
① 获取素材 ──→ ② 切片/整理 ──→ ③ 绑定动作 ──→ ④ 内容配置 ──→ ⑤ 导出上线
 (上传/AI/库)   (网格切片/排序)  (动作×状态×段落)  (资料/食物/文本)  (校验/打包/放入mod)
```

每个环节在软件中都有独立可视化界面，全部完成前无需接触任何配置文件。

---

## ① 获取素材（三条通道）

### 通道 A：手动上传图片（推荐，入口遍布全软件）

素材工坊第一入口是**素材库**——所有原始素材先统一上传入库、分类管理，再进入后续流程：

| 入口位置 | 用途 |
|---|---|
| 素材工坊 → 素材库 → 「上传原始素材」拖拽区 / 「系统对话框选择」 | **原始素材统一入口**（立绘/精灵图/逐帧原图） |
| 素材库 → 分类筛选（原始素材/动画帧/图标/AI 生成）+ 搜索 | 素材管理；选中后可 **去切片 / 镜像 / 绑定为动画帧 / 设为模组图标 / 重命名 / 删除** |
| 素材工坊 → 生成向导 → 「手动上传图片」 | 直接走流水线：多张逐帧序列图或一张精灵图 |
| 动画工坊 → 「直接上传帧」/「从素材库添加」 | 给当前动作变体追加帧 |
| 宠物资料 → 图标选择 | 模组图标(自动居中裁剪 500×500) |
| 食物物品 → 编辑弹窗 | 物品图标 |

**素材规范（重要）**：

- 格式 **PNG 透明背景**（游戏桌面透明显示的关键），颜色模式 RGBA
- 帧内角色**大小一致、脚底对齐**，否则动画会跳动
- 单帧建议 200~500px 高；同一动画的所有帧尺寸相同
- 帧序列文件名按顺序命名（`walk_1.png walk_2.png …`），导入时按自然顺序排列
- 精灵图（sprite sheet）：多帧横/纵向拼在一张大图，进入②切片

### 通道 B：AI 生成（模板库直出素材）

AI 管理与生成 → AI 生成：

1. 先在「服务商管理」添加 OpenAI 兼容接口（内置 OpenAI / 智谱 GLM 预设，支持中转站），填入 API Key 与**生图模型**，点「测试」确认连通。
2. **🎭 角色与画风设定**（保存在项目中）：写清物种/毛色/服装/配饰/性格，选择画风（Q版厚涂/像素/赛璐璐/水彩/3D盲盒/黏土）——所有模板共用这套设定，保证多张素材角色一致。
3. **📚 模板库一键套用**（内置 9 个）：待机呼吸 / 行走循环 / 互动反应 / 睡觉 / 被提起 / 状态变化（以上为精灵图模板，可调 2~8 帧）+ 模组图标 / 食物图标 / 角色立绘（单张）。模板会自动拼装含精灵图规范（横向等大排列、脚底基线对齐、透明背景、无文字水印）的完整提示词，可在下方继续手动微调。
4. 生成结果上的操作：
   - **入库**：存入素材库（AI 生成分类）
   - **入库并去切片**：精灵图模板专属——直接跳到素材工坊切片向导，走完 ②③ 绑定动作，实现「提示词 → 动画」一条龙
5. 文案助手：宠物介绍 / 低状态台词 / 起名建议，生成后一键回填。

> AI 生成的精灵图常出现帧不等大/带底色的情况：切片时用「格间距/外边距」微调，或在③之前把需要的格子逐帧修图后再上传。角色立绘适合作为手绘/AI 重绘的参考底稿。

### 通道 C：素材库复用

所有来源（上传/切片/AI/镜像）的图片统一入素材库，带来源标记；可多选后：
- 🪞 **水平镜像**：批量生成镜像图 —— 左右行走/爬行动画只需画一个方向
- 🎬 **绑定为动画帧**：直接指定动作类型/状态/段落生成动画变体

## ② 切片与帧整理

### 精灵图切片（素材工坊 → 生成向导）

1. 上传一张精灵图（或单张宽图会被自动识别进入切片）。
2. 设置**列数/行数**（会按图片纵横比预猜）、**外边距**、**格间距**。
3. 预览图中绿格=保留帧，点击格子可剔除；顺序为从左到右、从上到下。
4. 「切出 N 帧，去整理」→ 进入帧整理。

### 帧整理

- **拖动卡片**调整帧顺序；
- 每帧右侧输入框改**时长(ms)**，默认 125ms（8fps），呼吸类 250ms 更自然，走路 100~150ms；
- 「应用到全部」批量设时长；
- 「水平镜像生成反向序列」一键得到反方向帧序列（如 `Walk_Right` 镜像自 `Walk_Left`）；
- 删除帧：悬停帧卡片右上角 ✕。

## ③ 绑定动作（动画如何组织）

点击「🎯 绑定到动作」后，先确认**目标宠物**（侧栏顶部的桌宠切换器决定当前编辑哪只——一个模组可以包含多只宠物，玩家在游戏内切换；每只宠物有独立的动画、资料与 `pet/<ID>/` 目录），再选择三个维度，软件自动落位到官方目录结构：

### 维度 1：动作类型（23 种，树中带 * 为必备）

| 分类 | 动作 | 目录形态 |
|---|---|---|
| 基础动作 | **呼吸/待机 Default\***、**开机 StartUP\***、关机 Shutdown、**说话 Say\***、**睡觉 Sleep\*** | `Default/` 等直接目录 |
| 互动动作 | 摸头 Touch_Head、摸身体 Touch_Body、**提起·静态/动态 Raised_\*** | `Raise/Raised_*` |
| 待机与随机 | 通用随机 Common、空闲 Idel、待机模式 StateONE/TWO | 具名/`State/` |
| 移动与工作 | 移动 Move（按动画名区分方向如 `Walk_Left`）、工作 Work（如 `Work_Read`） | `<类型>/<动画名>/` |
| 状态切换 | Switch_Up/Down/Thirsty/Hunger | `Switch/<Up…>/` |
| 侧边贴靠 | SideHide_* | 同名目录 |

### 维度 2：身体状态（4 种）

`Happy 开心 / Nomal 普通 / PoorCondition 状态不佳 / Ill 生病`。
同一动作每个状态可配不同动画；只做一套选「普通」，其余状态自动回落。

### 维度 3：段落（一段式 vs 三段式）

- 一段式动作（Default/StartUP/Shutdown/Switch/Raised_Dynamic）：单一帧序列循环/单次播放
- 三段式动作（Touch_Head/Touch_Body/Sleep/Raised_Static/State/具名动画）：
  - **A 开始**：起手帧（摸头前伸手）
  - **B 循环**：持续循环（被摸中）
  - **C 结束**：收尾帧
  - 全配齐衔接最自然，只配 B 也能工作

绑定完成 → 「去动画工坊预览」可实时播放（三段式自动模拟 A→B×2→C 连播）。

> 同一槽位可添加多个**变体**（如待机随机小动作），游戏中会被随机抽播。

## ④ 内容配置

| 配置 | 位置 | 要点 |
|---|---|---|
| 宠物资料 | 宠物资料页 | 名称/介绍必填；摸头/摸身体判定区默认值即可工作 |
| 模组图标 | 宠物资料页 | 500×500，选图后自动裁剪 |
| 多语言 | 宠物资料页 | zh-CN 默认，可加 en-US 等，导出 lang/ |
| 食物物品 | 食物页 | 8 类型（正餐/零食/饮料/功能/药品/礼物/收藏/通用），数值正=恢复负=消耗 |
| 对话文本 | 文本页 | 支持 `{name} {food} {feel} {money} {level}` 等变量；点击/选项文本可设状态、时段、好感条件 |
| 工作配置 | 工作区（宠物 lps） | 工作/学习/玩耍，与 `Work/<动画名>` 关联 |

## ⑤ 导出上线

1. **导出模组页**查看校验：红=必须修复（缺 Default 动画等），黄=建议补充。
2. 点「📦 导出模组」选位置 → 生成：
   - `<模组ID>/` 文件夹（info.lps、icon.png、lang、pet、food、image、text）
   - 可选 `.zip`（分享/创意工坊用）
3. **安装**：把导出的**文件夹**放入 `Steam\steamapps\common\VPet\mod\`（或游戏目录 `mod\`），重启游戏 → 设置 → 模组 → 启用。
4. 调试技巧：改完重新导出覆盖同目录即可热加载测试。
